<h1> ESP-32_Mini-Interface</h1>
<p> 
A simple interface project for ESP32 with a TFT display.
<br>
Built to experiment with embedded systems and ESP32 development.
</p>
<h2>Software / Technologies</h2>
<ul>  
<li>ESP32 as know as Esp32</li>
<li>Arduino Integrated Development Environment</li>
<li>TFT_eSPI Libary </li>
<li>The Esp32's own BLE Libary</li>
<li>The Esp32's own Wi-Fi Libary</li>
<li>The FS Libary</li>
<li>The littleFS libary</li>
<li>The WebServer Libary</li>
</ul>

<h1> The Hardware</h1>
<ul> 
<li>ESP32 Devkit_V1</li>
<li>TFT Screen that uses TFT_eSPI libary minimum Resulation 128x160</li>
<li>3 buttons and a buzzer (the buzzer is optional)</li>
</ul>
